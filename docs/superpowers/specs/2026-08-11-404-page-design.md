# Design — Pagina 404

## Obiettivo

Creare una pagina `404.html` e configurare il server Express perché restituisca
questa pagina (con status HTTP 404) quando l'utente visita una route sconosciuta,
con un pulsante "Torna alla Home" per riportarlo alla pagina principale.

Comportamento scelto dall'utente: pagina 404 con link Home, senza redirect automatico.

## File coinvolti

### 1. `public/404.html` (nuovo)

Pagina HTML conforme alle convenzioni del sito:

- `lang="it"`, title "Pagina non trovata — Bike Training Manager"
- Header identico alle altre pagine (logo + `css/style.css`)
- Main centrato con la classe `auth-container`/`card` già esistente:
  - Icona Font Awesome (`fa-solid fa-route` o simile)
  - Titolo "Errore 404 — Pagina non trovata"
  - Messaggio che indica che la pagina richiesta non esiste
  - Pulsante `.btn-primary` con link a `index.html`
- Footer identico alle altre pagine
- Non richiede modifiche a CSS o JS

### 2. `server/server.js` (modifica)

Aggiungere un middleware catch-all DOPO i middleware esistenti
(`express.static` e route `/api`), PRIMA del middleware di gestione errori:

- Se `req.path` NON inizia con `/api`: rispondere `res.status(404).sendFile(...)`
  di `public/404.html`
- Se `req.path` inizia con `/api` (route API sconosciuta): rispondere
  `res.status(404).json({ success: false, message: 'Risorsa non trovata' })`

## Verifica

- Avviare il server e verificare:
  - `GET /xyz` → status 404 + `404.html` con pulsante Home funzionante
  - `GET /api/xyz` → status 404 + risposta JSON
  - Le route esistenti (`/`, `/login.html`, `/dashboard.html`, API attive)
    continuano a funzionare

## Fuori scope

- Nessuna modifica a CSS o alle pagine esistenti
- Nessun redirect automatico dopo un timeout
