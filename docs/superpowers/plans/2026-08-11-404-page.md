# Pagina 404 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aggiungere una pagina `404.html` e un middleware catch-all in Express che la serve (con status 404) per le route sconosciute, mantenendo 404 JSON per le route `/api` ignote.

**Architecture:** Il progetto serve file statici da `public/` via `express.static`. Un middleware catch-all posizionato dopo i router `/api` intercetta ogni richiesta non gestita: per i percorsi non `/api` serve `public/404.html` con `res.status(404).sendFile(...)`; per i percorsi `/api` ignoti restituisce un 404 JSON.

**Tech Stack:** Node.js, Express 5 (`server/server.js`), HTML/CSS vanilla con stile esistente in `public/css/style.css`.

## Global Constraints

- Le pagine usano `lang="it"` e sono in italiano.
- Stile coerente con `public/css/style.css` (className già esistenti: `container`, `card`, `btn`, `btn-primary`, `auth-container`, ecc.). Nessuna modifica al CSS.
- Title e copy in italiano, con marchio "Bike Training Manager".
- Non committare (nessun commit richiesto dall'utente).

### Task 2: Aggiungere il middleware catch-all in `server/server.js`

**Files:**
- Modify: `server/server.js` (inserire dopo la riga 23, prima del middleware errori)

**Interfaces:**
- Consumes: `path` già importato (riga 3)
- Produces: risposta 404 per ogni route non gestita; per `/api/xyz` risposta JSON 404.

- [ ] **Step 1: Aggiungere il codice**

Inserire subito dopo la riga con `app.use('/api', goalsRoutes);` e PRIMA del middleware di gestione errori:

```javascript
// Pagina 404 per route sconosciute
app.use((req, res) => {
    if (req.path.startsWith('/api')) {
        res.status(404).json({ success: false, message: 'Risorsa non trovata' });
    } else {
        res.status(404).sendFile(path.join(__dirname, '..', 'public', '404.html'));
    }
});
```

- [ ] **Step 2: Verificare con curl**

Avviare il server con `npm start`.

- `curl -i http://localhost:3000/xyz`
  Expected: `HTTP/1.1 404 Not Found` e body contenente `Errore 404`.
- `curl -i http://localhost:3000/api/xyz`
  Expected: `HTTP/1.1 404 Not Found` e body JSON `{"success":false,"message":"Risorsa non trovata"}`.
- `curl -i http://localhost:3000/`
  Expected: `HTTP/1.1 200 OK` (la landing page funziona ancora).
- `curl -i http://localhost:3000/login.html`
  Expected: `HTTP/1.1 200 OK`.
